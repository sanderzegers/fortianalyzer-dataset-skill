# `$log-anomaly` — Anomaly Detection Logs

> **Not a separate table.** On FAZ 7.6, `$log-anomaly` returns exactly the same rows as `$log-attack`, IPS signature rows included. Anomaly (DoS policy) logs are the `subtype='anomaly'` rows of the attack table, so always filter `subtype='anomaly'`. See cols-slog.md.

Anomaly logs capture detected abnormal behavior patterns on the FortiGate — unusual traffic volumes, brute-force attempts, port scans, application anomalies, and other statistical deviations from baseline. These logs are generated by the FortiGate's anomaly detection engine (UTM profile).

All common columns apply where relevant (see cols-common.md).
